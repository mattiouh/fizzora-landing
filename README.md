# FIZZORA — Landing Page Demo

Independent Concept / Portfolio Project per un brand DTC fittizio di bevande frizzanti.

## Direzione creativa

- **Brand:** FIZZORA, energia urbana e gioco visivo controllato.
- **Palette:** cream editoriale, ink profondo, acid lime, cherry red, orange rush, electric blue.
- **Tipografia:** Space Grotesk per impatto e gerarchia, Manrope per leggibilità, DM Mono per dettagli retail.
- **Conversione:** CTA above-the-fold, navigazione ridotta, selezione gusti e bundle, proof, FAQ anti-frizione, CTA mobile sticky e cart drawer demo.

## Avvio

Apri `index.html` in un browser o pubblica la cartella come sito statico. Non sono necessari build step o dipendenze.
